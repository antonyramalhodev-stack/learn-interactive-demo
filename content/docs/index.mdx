This site shows the interactive elements you can add to a docs or learning site that runs on GitHub Pages. No server runs behind it. Every element works in the browser.

<Callout title="Demo site">
  The lesson text is sample content. This is a prototype built with open-source tools, not an
  official GitHub site.
</Callout>

## Also on every page

- **Search.** Select the search box or press <kbd>Ctrl</kbd>+<kbd>K</kbd>. On macOS, press <kbd>⌘</kbd>+<kbd>K</kbd>. Search runs in the browser from a static index.
- **Light and dark mode.** Use the theme switch in the sidebar. The Primer colors change with it.
- **Copy as Markdown.** Each page has a button that copies the page as Markdown.
- **On this page.** The table of contents follows your scroll position.
