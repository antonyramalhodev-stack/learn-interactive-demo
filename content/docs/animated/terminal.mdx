---
title: Terminal
description: A terminal session that types itself when the reader scrolls to it.
---

The `Terminal` element plays back a session. Commands type out one character at a time, and output appears at once. Nothing runs, so the element is safe on a static site.

## Try it

Select the replay button in the title bar to watch it again. The copy button copies the commands only.

<Terminal title="Create a branch">{`
$ git switch -c update-readme
Switched to a new branch 'update-readme'
$ git add README.md
$ git commit -m "Update README"
# Push the branch and set its upstream
$ git push -u origin update-readme
`}</Terminal>

## How you write it

Paste the session between the tags, inside `` {`...`} ``. Start a command with `$` and a comment with `#`. Every other line is output.

```mdx
<Terminal title="Create a branch">{`
$ git switch -c update-readme
Switched to a new branch 'update-readme'
# Push the branch and set its upstream
$ git push -u origin update-readme
`}</Terminal>
```

## Motion and accessibility

The session starts when the terminal scrolls into view. When the reader's system asks for reduced motion, every line shows at once with no typing.
