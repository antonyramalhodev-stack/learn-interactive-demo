---
title: Timeline
description: A sequence of events that appear one after another.
---

The `Timeline` element shows what happens, in order. It uses the Primer Timeline component, so the badges and the connecting line match GitHub. The events appear one after another when the reader scrolls to the timeline.

## Try it

<Timeline>
  <Event icon="commit" title="You commit a change on a branch" />
  <Event icon="pull-request" color="success" title="You open a pull request" />
  <Event icon="review" color="accent" title="A reviewer reads the change">
    The reviewer can comment, approve, or request changes.
  </Event>
  <Event icon="merge" color="done" title="A maintainer merges the pull request" />
</Timeline>

## How you write it

Add one `Event` tag for each event. Text between the tags becomes the detail under the title.

```mdx
<Timeline>
  <Event icon="commit" title="You commit a change on a branch" />
  <Event icon="pull-request" color="success" title="You open a pull request" />
  <Event icon="review" color="accent" title="A reviewer reads the change">
    The reviewer can comment, approve, or request changes.
  </Event>
  <Event icon="merge" color="done" title="A maintainer merges the pull request" />
</Timeline>
```

## Motion and accessibility

A screen reader reads the events in order. With reduced motion, every event shows at once.
