---
title: Commit graph
description: A commit graph that draws itself one step at a time.
---

The `GitGraph` element turns a short history into a commit graph. Each step draws a line and a commit, and the caption explains the step. The reader can play the steps or move through them with the arrows.

## Try it

<GitGraph title="Feature branch flow">{`
commit main: Start from the default branch
branch feature from main: Create a branch named feature
commit feature: Commit your first change
commit main: Someone else commits to main
commit feature: Commit a second change
merge feature into main: Merge feature into main
`}</GitGraph>

## How you write it

Write one event on each line. The text after the colon is the caption for that step.

```mdx
<GitGraph title="Feature branch flow">{`
commit main: Start from the default branch
branch feature from main: Create a branch named feature
commit feature: Commit your first change
merge feature into main: Merge feature into main
`}</GitGraph>
```

A line takes one of three forms:

| Line | What it draws |
| --- | --- |
| `commit BRANCH: caption` | A commit on a branch |
| `branch NEW from BRANCH: caption` | A new branch that starts from another branch |
| `merge BRANCH into TARGET: caption` | A merge of one branch into another |

## Motion and accessibility

The graph has a text alternative that lists every step in order. With reduced motion, the graph shows the final state.
