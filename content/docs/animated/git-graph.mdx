---
title: Commit graph
description: A commit graph that draws itself one step at a time.
---

The `GitGraph` component turns a list of events into a commit graph. Each step draws a line and a commit, and the caption explains the step. The reader can play the steps or move through them with the arrows.

## Try it

<GitGraph
  title="Feature branch flow"
  events={[
    { type: 'commit', branch: 'main', label: 'Start from the default branch' },
    { type: 'branch', branch: 'feature', from: 'main', label: 'Create a branch named feature' },
    { type: 'commit', branch: 'feature', label: 'Commit your first change' },
    { type: 'commit', branch: 'main', label: 'Someone else commits to main' },
    { type: 'commit', branch: 'feature', label: 'Commit a second change' },
    { type: 'merge', branch: 'feature', into: 'main', label: 'Merge feature into main' },
  ]}
/>

## How you write it

An event is a `commit`, a `branch`, or a `merge`. The component assigns a lane and a color to each branch in the order the branches appear.

```mdx
<GitGraph
  title="Feature branch flow"
  events={[
    { type: 'commit', branch: 'main', label: 'Start from the default branch' },
    { type: 'branch', branch: 'feature', from: 'main', label: 'Create a branch named feature' },
    { type: 'commit', branch: 'feature', label: 'Commit your first change' },
    { type: 'merge', branch: 'feature', into: 'main', label: 'Merge feature into main' },
  ]}
/>
```

## Motion and accessibility

The graph has a text alternative that lists every step in order. With reduced motion, the graph shows the final state.
