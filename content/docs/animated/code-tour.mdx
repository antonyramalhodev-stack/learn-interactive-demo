---
title: Code tour
description: A guided walk through a code sample, one highlight at a time.
---

The `CodeTour` element shows a code sample and a set of stops. A highlight slides to the lines for each stop, the other lines dim, and a note explains what the reader sees.

## Try it

<CodeTour
  title="deploy.yml"
  code={`on:
  push:
    branches: [main]

jobs:
  build:
    runs-on: ubuntu-latest
    steps:
      - run: npm ci
      - run: npm run build
  deploy:
    needs: build`}
>
  <Stop lines="1-3" title="The trigger">The workflow starts on every push to the main branch.</Stop>
  <Stop lines="6-10" title="The build job">The job installs the dependencies and builds the static site.</Stop>
  <Stop lines="11-12" title="The deploy job">The needs key makes the deploy job wait for the build job.</Stop>
</CodeTour>

## How you write it

Put the code in the `code` value, then add one `Stop` tag for each stop. The text between the tags is the note.

```mdx
<CodeTour
  title="deploy.yml"
  code={`on:
  push:
    branches: [main]`}
>
  <Stop lines="1-3" title="The trigger">The workflow starts on every push to the main branch.</Stop>
</CodeTour>
```

## Properties

<TypeTable
  type={{
    code: {

      type: 'string',

    title: {
      description: 'The text in the title bar, for example a file name.',
      type: 'string',
      default: "'Code tour'",
    },
    autoPlay: {
      description: 'Move through the stops on a timer until the reader takes over.',

      default: 'false',
    },
  }}
/>
