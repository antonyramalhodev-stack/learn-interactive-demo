## Theme playground

The `ThemePlayground` component previews a lesson card in seven Primer color themes. Each theme is a set of CSS variables from `@primer/primitives`, so the same components change color with no other code.

The preview steps through the themes until you pick one.

<ThemePlayground />

How you write it:

```mdx
<ThemePlayground />
```

How it works: the component sets three attributes on the preview element. Primer applies the matching theme to that element and everything inside it.

```html
<div data-color-mode="dark" data-light-theme="light" data-dark-theme="dark_dimmed">
  ...
</div>
```

## Layer stack

The `LayerStack` component shows the parts of a system as layers. The selected layer slides out of the stack and its description opens.

<LayerStack
  layers={[
    {
      name: 'Content',
      tech: 'MDX',
      text: 'Lessons live in .mdx files. Writers add an element with one tag.',
    },
    {
      name: 'Components',
      tech: '@primer/react',
      text: "The widgets use GitHub's React components and icons.",
    },
    {
      name: 'Framework',
      tech: 'Fumadocs + Next.js',
      text: 'Fumadocs adds the layout, the sidebar, and search. Next.js exports static files.',
    },
    {
      name: 'Hosting',
      tech: 'GitHub Pages',
      text: 'GitHub Actions builds the site, and GitHub Pages serves it.',
    },
  ]}
/>

How you write it:

```mdx
<LayerStack
  layers={[
    { name: 'Content', tech: 'MDX', text: 'Lessons live in .mdx files.' },
    { name: 'Hosting', tech: 'GitHub Pages', text: 'GitHub Pages serves the site.' },
  ]}
/>
```
