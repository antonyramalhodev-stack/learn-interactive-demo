title: GitHub branding
description: How the site gets GitHub's look from the Primer design system.
---

Primer is GitHub's open-source design system. Every element on this site takes its colors, spacing, type, and icons from Primer, so new elements match the others with no extra design work.

| Package | What it provides |
| --- | --- |
| `@primer/react` | React components such as buttons, forms, and labels |
| `@primer/primitives` | Design tokens: the colors, spacing, and type scale as CSS variables |
| `@primer/octicons-react` | The Octicons icon set |

The site font is Mona Sans, loaded from the `@fontsource-variable/mona-sans` package.

## Use a Primer component in your own element

Import the component in a client component, then add your element to the list in `src/components/elements/index.ts` so your pages can use it.

```tsx title="src/components/elements/star-button.tsx"
'use client';

import { useState } from 'react';
import { Button } from '@primer/react';
import { StarIcon } from '@primer/octicons-react';

export function StarButton() {
  const [starred, setStarred] = useState(false);

  return (
    <Button leadingVisual={StarIcon} onClick={() => setStarred(!starred)}>
      {starred ? 'Starred' : 'Star'}
    </Button>
  );
}
```

## Use the tokens in CSS

The Primer tokens are CSS variables, so your own styles can use the same colors and spacing as the components.

```css title="src/components/elements/panel.module.css"
.panel {
  border: var(--borderWidth-thin) solid var(--borderColor-default);
  border-radius: var(--borderRadius-medium);
  background: var(--bgColor-default);
}
```

## How the theme works

The file `src/app/global.css` maps the Fumadocs color variables to Primer tokens. The sidebar, the callouts, the search dialog, and the code blocks all pick up the same colors in light and dark mode.

```css title="src/app/global.css"
html:root,
html.dark {
  --color-fd-background: var(--bgColor-default);
  --color-fd-foreground: var(--fgColor-default);
  --color-fd-border: var(--borderColor-default);
  --color-fd-primary: var(--fgColor-accent);
}
```
