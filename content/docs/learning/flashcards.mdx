---
title: Flashcards
description: A deck of terms that flip to show the answer.
---

The `Flashcards` element shows one card at a time. The learner selects the card to flip it, and uses the arrow buttons to move through the deck.

## Try it

<Flashcards>
  <Flashcard term="Repository">A project folder that Git tracks, with its full history.</Flashcard>
  <Flashcard term="Fork">Your own copy of someone else's repository.</Flashcard>
  <Flashcard term="Clone">A copy of a repository on your computer.</Flashcard>
  <Flashcard term="Merge">Combine the changes from one branch into another.</Flashcard>
</Flashcards>

## How you write it

Add one `Flashcard` tag for each card. The `term` goes on the front, and the text between the tags goes on the back.

```mdx
<Flashcards>
  <Flashcard term="Repository">A project folder that Git tracks, with its full history.</Flashcard>
  <Flashcard term="Fork">Your own copy of someone else's repository.</Flashcard>
</Flashcards>
```
