---
title: Knowledge check
description: A single-choice question with feedback for each answer.
---

The `Quiz` element asks one question. The learner picks an answer and selects **Check answer**. Each answer can carry its own feedback, so a wrong answer still teaches something.

## Try it

<Quiz question="Which file format do the pages of this site use?">
  <Answer correct feedback="Each page is an .mdx file: Markdown that can also render elements.">MDX</Answer>
  <Answer feedback="YAML appears in the front matter and the workflow file. The page content is MDX.">YAML</Answer>
  <Answer feedback="The build produces HTML, but you write the pages in MDX.">HTML</Answer>
</Quiz>

## How you write it

Add one `Answer` tag for each answer. Add the word `correct` to the right one.

```mdx
<Quiz question="Which file format do the pages of this site use?">
  <Answer correct feedback="Each page is an .mdx file.">MDX</Answer>
  <Answer feedback="The page content is MDX.">YAML</Answer>
  <Answer feedback="You write the pages in MDX.">HTML</Answer>
</Quiz>
```
