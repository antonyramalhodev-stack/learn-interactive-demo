---
title: Knowledge check
description: A single-choice question with feedback for each answer.
---

The `Quiz` component asks one question. The learner picks an answer and selects **Check answer**. Each option can carry its own feedback, so a wrong answer still teaches something.

## Try it

<Quiz
  question="Which file format do the pages of this site use?"
  options={[
    {
      label: 'MDX',
      correct: true,
      feedback: 'Each page is an .mdx file: Markdown that can also render components.',
    },
    {
      label: 'YAML',
      feedback: 'YAML appears in the front matter and the workflow file. The page content is MDX.',
    },
    {
      label: 'HTML',
      feedback: 'The build produces HTML, but you write the pages in MDX.',
    },
  ]}
/>

## How you write it

```mdx
<Quiz
  question="Which file format do the pages of this site use?"
  options={[
    { label: 'MDX', correct: true, feedback: 'Each page is an .mdx file.' },
    { label: 'YAML', feedback: 'The page content is MDX.' },
    { label: 'HTML', feedback: 'You write the pages in MDX.' },
  ]}
/>
```
