---
title: Command exercise
description: The learner types a command and the page checks it.
---

The `CommandExercise` element gives the learner a task and a command line. It compares the text with the commands you accept. It doesn't run the command, so it works on a static site.

## Try it

<CommandExercise
  prompt="Show the commit history of the current branch, one line for each commit."
  hint="Use git log with the --oneline option."
  placeholder="git ..."
>{`
git log --oneline
`}</CommandExercise>

## How you write it

Write the accepted commands between the tags, one on each line. Extra spaces in the learner's answer don't matter.

```mdx
<CommandExercise
  prompt="Create a branch named fix-typo and switch to it."
  hint="Use git switch with the -c option."
>{`
git switch -c fix-typo
git checkout -b fix-typo
`}</CommandExercise>
```
