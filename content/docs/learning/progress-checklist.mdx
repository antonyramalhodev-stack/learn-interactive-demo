---
title: Progress checklist
description: A checklist with a progress bar that the browser saves.
---

The `Checklist` component tracks the tasks in a lesson. The learner's browser saves the progress, so it's still there after a reload.

## Try it

Select a few items, then reload the page.

<Checklist
  id="demo-checklist"
  title="Explore this demo"
  items={[
    'Open the sample lesson',
    'Answer a knowledge check',
    'Flip a flashcard',
    'Switch between light and dark mode',
    'Search for a page',
  ]}
/>

<Callout title="Where the progress lives" type="warn">
  The component saves progress in the browser's local storage. Progress doesn't follow the
  learner to another browser or device. To sync progress across devices, you need a service
  with sign-in, which a static site doesn't have.
</Callout>

## How you write it

```mdx
<Checklist
  id="demo-checklist"
  title="Explore this demo"
  items={['Open the sample lesson', 'Answer a knowledge check']}
/>
```

## What it uses

The component uses `CheckboxGroup`, `Checkbox`, `FormControl`, `ProgressBar`, `Label`, and `Button` from Primer React. The source is in `src/components/learn/checklist.tsx`.
